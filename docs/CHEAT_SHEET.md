# MFL Cheat Sheet
**Author:** @freyley.leyva

| Quiero... | Comando / lugar |
|---|---|
| Ver archivos | `dir` |
| Abrir VS Code | `code .` |
| Levantar MFL | `docker compose up -d` |
| Ver servicios | `docker compose ps` |
| Ver logs | `docker compose logs -f api` |
| Detener MFL | `docker compose down` |
| Abrir UI | http://localhost:8501 |
| Swagger | http://localhost:8000/docs |
| Qdrant | http://localhost:6333/dashboard |
| Jaeger | http://localhost:16686 |
